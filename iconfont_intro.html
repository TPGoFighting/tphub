Overview

为什么 Web 开发绕不开它

对国内前端来说，Iconfont 不只是「图标网站」——它是把零散 SVG 收拢成可管理、可主题化、可商用交付的资源中枢。

📦

海量资源

库内超过 3356 万枚矢量图标，中文关键词即可命中，几乎能找到任意业务所需的图形。

📐

矢量无损

SVG / Icon Font 均为矢量，任意缩放不糊，适配从手表到 4K 屏的全设备分辨率。

⚡

Icon Font 性能

整套图标打包成一个字体文件，比多张 PNG 精灵图更小、请求更少，首屏加载更快。

🎨

图标颜色、大小、阴影、旋转全部交给 CSS 控制，告别为换色再导一张图的重复劳动。

直接输入「分享」「购物车」「下载」就能搜到对应图标，比英文关键词检索更贴合国内场景。

Deep Dive

三种引入方式，怎么选

同一个图标项目可同时导出四种形态。选哪种，取决于你对「动态性 / 多色 / 体积」的取舍。

🅰 Font class

最常用。在线 link 引入 CSS，用 <i class="iconfont icon-xxx"> 调用。单色、改色靠 color，体积小。

🅱 Symbol

引入一段 JS + SVG sprite，<use> 引用。支持多色图标，适合复杂图形与主题切换。

🅲 Unicode

最轻量，直接用字体编码 &#xe601;。兼容性最好，但无法用语义类名、不利维护。

💡 结论：新项目默认选 Font class（简单、可控）；需要渐变/多色图标时切到 Symbol；纯静态展示且追求极致兼容再考虑 Unicode。SVG 源码下载则用于设计稿二次编辑。

Code

真实可跑的引入代码

下面三段都取自 Iconfont「我的项目 → 下载/生成代码」产出的真实形态（font 编号与项目名以你自己的为准）。

<!-- 1) 在 <head> 引入在线 CSS（编号换成你项目的） -->
<link rel="stylesheet" href="//at.alicdn.com/t/font_1234567_abcdef.css">

<!-- 2) 在 HTML 里用语义类名调用图标 -->
<i class="iconfont icon-gouwuche"></i>

<!-- 3) 用 CSS 控制颜色 / 大小（无需再导出图片） -->
.iconfont {
  color: #c2892b;          /* 图标颜色 */
  font-size: 24px;          /* 图标大小 */
}
⚠️ 在线 link 依赖阿里 CDN（at.alicdn.com）。生产环境建议把下载的 iconfont.css 与字体文件本地化，避免外链抖动影响图标渲染。
<!-- 1) 引入 Symbol JS（单个项目一份即可） -->
<script src="//at.alicdn.com/t/font_1234567_abcdef.js"></script>

<!-- 2) 用 <svg> + <use> 引用，支持多色图标 -->
<svg class="icon" aria-hidden="true">
  <use xlink:href="#icon-gouwuche"></use>
</svg>

<!-- 3) 给 svg 设尺寸；多色由图标自身 path 决定 -->
.icon { width: 1.4em; height: 1.4em; fill: currentColor; }
💡 Symbol 方式把整组图标塞进一个 SVG sprite，多色、渐变都能保留，是复杂视觉方案（如品牌插画图标）的首选。
<!-- 1) 先声明字体族 -->
.iconfont {
  font-family: "iconfont" !important;
  font-style: normal;
  -webkit-font-smoothing: antialiased;
}

<!-- 2) 直接写 Unicode 实体，最轻量 -->
<i class="iconfont">&#xe601;</i>
<i class="iconfont">&#xe602;</i>
⚠️ Unicode 方式没有语义类名，后期维护靠记编码，团队项目不推荐；适合一次性静态展示页。

Tip 1
同一项目统一一种引入方式

别把 Font class 和 Symbol 混用在同一套 UI 里，否则类名与 sprite 互相覆盖，样式难以收口。

Tip 2
本地化字体文件

把生成好的 iconfont.css + 字体文件随代码仓库提交，避免外部 CDN 抖动导致图标空白。

Tip 3
靠授权筛选规避风险

商用项目在搜索时勾选「可商用」协议，确认每个图标的授权类型后再进生产。

FAQ

高频问题

01

Iconfont 和直接放 SVG 有什么区别？

＋
直接内联 SVG 可控性最强、能多色，但每个图标占一份 DOM、难以统一管理。Iconfont 把图标收进字体 / sprite，用统一类名调用，体积更小、换色改尺寸只动 CSS。要单图精细控制时用 SVG 源码，要成体系图标系统时用 Iconfont。
02

Font class、Symbol、Unicode 怎么选？

＋
三者取舍：
  • Font class：单色图标、要改色、求简单——默认选它
  • Symbol：需要多色 / 渐变 / 主题切换——功能最全
  • Unicode：极端追求兼容与体积、不计维护性——最后考虑
03

图标能商用吗？会不会有版权风险？

＋
每个图标在详情页都标注授权协议。搜索时勾选「可商用」筛选，只采这类资源即可规避风险。但要注意：平台资源授权 ≠ 商标权，涉及品牌 LOGO、特定企业标识的图标仍需另行确认。
04

为什么图标显示成方框 / 空白？

＋
常见三类原因：
  • 在线 link 的 CDN（at.alicdn.com）加载失败或被墙——把字体文件本地化
  • 类名写错，未匹配项目里实际生成的 icon-xxx
  • 字体文件 404，@font-face 路径与部署目录不符
05

团队协作时怎么管理图标？

＋
用「我的项目」建集合并邀请成员协作；每次增删图标后重新生成代码、随仓库提交。把 iconfont.css 和字体文件纳入版本管理，就能像管依赖一样管图标，避免各端各引一份。
06

和 iconify、Font Awesome 比，Iconfont 强在哪？

＋
Iconfont 的优势是中文搜索与海量本土化图标（3356 万级），很多国内业务专属图形在外文库里找不到。iconify / Font Awesome 胜在 npm 生态与框架集成。混合方案：通用图标用 Font Awesome，本土化图标从 Iconfont 抓取后转 SVG 并入。
Quick Start

五分钟接入你的第一个项目

从注册到页面出现图标，只需要「搜 → 收 → 建项目 → 选格式 → 引代码」五步。下面是三种引入方式的真实落地代码，默认展开最通用的 Font class。

// 1) 在 iconfont.cn 搜图标 → 加购物车 → 我的项目 → 新建项目
// 2) 项目里「生成 Font class 代码」，复制在线链接

<!-- index.html 的 <head> 中 -->
<link rel="stylesheet" href="//at.alicdn.com/t/font_1234567_abcdef.css">

<!-- 任意位置调用 -->
<button><i class="iconfont icon-gouwuche"></i> 购物车</button>

// 3) 在样式里控制外观
.icon-gouwuche { color: #cf5b3e; font-size: 20px; }
✅ 跑通标志：页面出现彩色/单色购物车图标，改 color 即时变色。下一步把 CSS 与字体文件下载到本地，提交进仓库。
// 项目里「生成 Symbol 代码」，复制 JS 链接

<!-- 引入一次 Symbol JS -->
<script src="//at.alicdn.com/t/font_1234567_abcdef.js"></script>

<!-- 多色图标用 <svg><use> 引用 -->
<svg class="icon" aria-hidden="true">
  <use xlink:href="#icon-gouwuche"></use>
</svg>

// 尺寸样式
.icon { width: 1.4em; height: 1.4em; fill: currentColor; }
// 项目里「生成 Unicode 代码」，复制字体声明

// 在 CSS 中声明字体
.iconfont {
  font-family: "iconfont" !important;
  font-style: normal;
  -webkit-font-smoothing: antialiased;
}

<!-- HTML 直接写实体 -->
<i class="iconfont">&#xe601;</i>
