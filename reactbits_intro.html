Overview

它不是 npm 包，而是一摞「可复制」的源码

ReactBits 把常见动画界面拆解成独立组件：你从官网预览、点 Copy Code、粘进项目、改 props 即可。底层统一是 Tailwind 负责样式、Framer Motion 负责动画，因此对现有 React 项目零侵入。

Deep Dive

从依赖到落地，三个真实步骤

下面用「装依赖 → 复制组件 → 改 props」的链路，把 ReactBits 的实际用法讲透。所有命令与代码均可在你本地复现。

01

底层依赖：只要 Tailwind + Framer Motion

＋
ReactBits 不发布自己的包，复制出的组件只用两个通用库。先确认项目里有它们：
  • tailwindcss：负责所有样式与断点（组件默认按 Tailwind v3/v4 类名书写）
  • framer-motion：负责 motion.* 元素与 animate / variants / transition
  • React 18+ 即可；没有 SSR 限制，Next.js / Vite / CRA 都能用
02

复制一个文本动画：Typewriter

＋
以官网 Text Animation 下的 Typewriter 为例（结构示意，真实 props 以官网 Copy Code 为准）： 
// Typewriter.tsx — 从 reactbits.dev 复制后直接可用
import { useState, useEffect } from "react";

export function Typewriter({ words, speed = 150 }: { words: string[]; speed?: number }) {
  const [text, setText] = useState("");
  const [i, setI] = useState(0);

  useEffect(() => {
    const timer = setTimeout(() => {
      setText(words[i]?.slice(0, text.length + 1) ?? "");
      if (text === words[i]) setI((i + 1) % words.length);
    }, speed);
    return () => clearTimeout(timer);
  }, [text, i, words, speed]);

  return <span className="font-mono">{text}_</span>;
}
03

用 props 定制：颜色、速度、触发

＋
大多数组件把可控参数暴露成 props。以 Card / Tilt 类组件为例，常见可改项：
  • speed / duration：动画时长（毫秒或秒）
  • 颜色：直接改 Tailwind 类名（如 text-[#e8743b] 或 bg-orange-500）
  • 尺寸：改 className 里的 w- / h- / text- 工具类
  • 触发：把无限循环改成 whileInView（Framer Motion）即可滚动进入视口才播放

FAQ

常见问题

01

ReactBits 要怎么安装？npm install 吗？

＋
不需要。ReactBits 没有自己的 npm 包，它是一个「复制即用」的源码库。你只需在项目中准备好 framer-motion 和 tailwindcss，然后从官网每个组件页点 Copy Code，把 .tsx 粘进你的 components/ 目录即可。好处是代码完全在你仓库里，不受上游发版节奏约束。
02

它和 Animate UI、Framer Motion 是什么关系？

＋
Framer Motion 是底层动画引擎；ReactBits 与 Animate UI 都是「站在它之上」的现成动画组件集合。区别有两点：① ReactBits 更偏「复制源码、自由改造」，组件数量 100+ 且种类更杂（背景、Loader、卡片都覆盖）；② Animate UI 更精简、更像传统组件库，适合「只想要少量动画增强」的项目。两者都依赖 Framer Motion，可共存。
03

复制出来的组件能直接跑吗？要不要配 Tailwind？

＋
能直接跑，但前提是项目已配置好 Tailwind——组件里的样式全是 Tailwind 工具类，没有内联兜底样式。若你的项目用 CSS Modules 或 styled-components，需要手动把类名翻成对应写法。动画逻辑本身只依赖 framer-motion 的 motion 组件，不依赖 Tailwind。
04

动画会不会拖慢我的页面性能？

＋
官方组件大多用 transform/opacity 这类走 GPU 合成的属性，本身就比改 width/top 更省。报告还建议：做无限循环背景时配合 will-change 或用 requestAnimationFrame 节流，低端设备更稳。如果你只想要一次性进场动画，把它改成 whileInView 还能减少常驻开销。
05

商业项目能用吗？版权会有问题吗？

＋
源码复制到你项目后，就归你把控。把它当普通开源代码片段使用即可——改颜色、速度、文案都在你本地完成。具体许可证以官网 Get Started / 仓库声明为准；接入前建议扫一眼授权页确认可商用的范围。
06

Next.js / SSR 项目能用吗？

＋
可以。ReactBits 组件是纯客户端 React 组件，React 18+ 即兼容，Next.js（App Router 下标 "use client"）、Vite、CRA 都能用。涉及 window / 监听的组件放在客户端组件里即可，无需特殊配置。
Quick Start

五分钟上手

核心就两件事：把底层依赖装好，再把组件源码复制进来。下面给出最稳的两条路径。

# 在已有 React 项目里装两个底层库（ReactBits 自身不用装）
npm install framer-motion
npm install -D tailwindcss @tailwindcss/postcss postcss autoprefixer

# 初始化 Tailwind（会生成 tailwind.config.js / postcss.config.js）
npx tailwindcss init -p
⚠️ 版本提醒：Tailwind v4 用 @import "tailwindcss" 的 CSS 入口，不再需要 content 数组；若你用 v3，请按官方保留 content: ["./src/**/*.{ts,tsx}"]。ReactBits 组件类名按对应版本书写。
// 1) 官网点 Copy Code，把组件存成文件
//    src/components/Typewriter.tsx

// 2) 在你的页面里 import 并渲染
import { Typewriter } from "./components/Typewriter";

export default function Hero() {
  return (
    <h1>
      <Typewriter words={["构建中", " shipping", "上线了"]} speed={120} />
    </h1>
  );
}
💡 复制后先 原样跑通，再改 props。这样能快速确认是组件问题还是你项目里 Tailwind / Framer Motion 没配好。
# 从零起一个 React + TS 项目并接好依赖
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install framer-motion
npm install -D tailwindcss @tailwindcss/postcss postcss

# 启动后去 reactbits.dev 复制组件粘进 src/components/
npm run dev

🔍 先预览再复制

每个组件页都有实时 demo，点一下看效果再决定要不要复制，避免盲目搬代码。

🎨 改 props 不动结构

颜色、速度、尺寸优先用 props 和 Tailwind 类改，不要重写动画逻辑。

📚 当 Framer Motion 教材

读源码能学到 variants、whileInView、staggerChildren 等高级用法。
