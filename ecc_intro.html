Deep Dive

六个核心系统，逐层点开

01

持续学习 v2 · Instinct 机制

＋
基于「本能(instinct)」的学习：会话结束后 evaluate-session 抽取模式，每条 instinct 带置信度评分。
  • /instinct-status 查看已学本能（默认最多注入 6 条，阈值 0.7，可用 env 调）
  • /instinct-import · /instinct-export 与他人共享
  • /evolve 把相关 instinct 聚合成正式 skill
  • 底层用 SQLite 状态库记录已装组件，支持增量更新与 ecc status 便携交接
02

AgentShield · 安全审计器

＋
独立 npm 包 ecc-agentshield（1282 测试、98% 覆盖、102 条静态规则）。扫描 CLAUDE.md / settings.json / MCP 配置 / hooks / agent 定义 / skills 五类：
  • 密钥检测（14 种模式）、权限审计、hook 注入分析、MCP 风险画像、agent 配置审查
  • --opus 启动 3 个 Opus 4.6 agent 做红队/蓝队/审计三角色对抗推理，而非简单模式匹配
  • 输出 A–F 终端评级 / JSON（CI）/ Markdown / HTML；发现严重项时 exit code 2，可直接做构建门禁
03

记忆持久化 · Memory Persistence

＋
多个 hook 在会话生命周期里自动存/取上下文。数据集中在单一 agent 数据根（默认 ~/.claude），可用 ECC_AGENT_DATA_HOME 为不同 harness（如 Cursor）隔离，避免互相覆盖：
  • session-data/ 会话摘要 · skills/learned/ 学到的 skill
  • session-aliases.json 会话别名 · metrics/ 成本与活跃度指标
  • ECC_SESSION_RETENTION_DAYS 控制保留窗口（默认 30 天）
04

Token 优化与验证循环

＋
长表单指南覆盖的主题：
  • Token 优化：模型选择、系统提示瘦身、后台进程、strategic-compact 压缩建议
  • 验证循环：checkpoint vs continuous eval、grader 类型、pass@k 指标
  • 子 agent 编排：上下文问题、迭代检索(iterative-retrieval)模式
05

并行化 · Parallelization

＋
用 Git worktree 做多实例并行，cascade 方法决定何时扩实例。multi-* 命令（multi-plan/execute/backend/frontend/workflow）需额外安装 ccg-workflow 运行时，提供 ~/.claude/bin/codeagent-wrapper 等外部依赖。
06

Hermes 操作员层 · ecc2 控制面

＋
v2.0.0 在可复用层之上叠了公开的 Hermes 操作员故事：控制面基底（session adapters + MCP inventory）、worktree-lifecycle 服务、orch-* 编排器家族。配套的 Rust 控制面原型 ecc2/ 已可本地构建，暴露 dashboard/start/sessions/status/stop/resume/daemon 命令（alpha 阶段）。

Quick Start

两分钟上手

Claude Code 用户通常只走一条安装路径——插件安装最省事；手动安装给更细的掌控。两者不要叠加。

# 1) 添加 marketplace
/plugin marketplace add https://github.com/affaan-m/ECC

# 2) 安装插件（规范标识 ecc@ecc）
/plugin install ecc@ecc

# 3) 使用（命名空间形式）
/ecc:plan "Add user authentication"
⚠️ 插件不会自动分发 rules（上游限制）。装完插件后，再手动 cp 你需要的 rules/ 目录到 ~/.claude/rules/ecc/，从 rules/common + 一种语言包起步即可。
# 克隆 + 依赖
git clone https://github.com/affaan-m/ECC.git && cd ECC
npm install

# 全量手动安装（不要与 /plugin install 叠加）
./install.sh --profile full        # 或 .\install.ps1 / npx ecc-install --profile full

# 低上下文路径：跳过 hooks
./install.sh --profile minimal --target claude
# 用户级规则（所有项目生效）
mkdir -p ~/.claude/rules/ecc
cp -r rules/common ~/.claude/rules/ecc/
cp -r rules/typescript ~/.claude/rules/ecc/   # 选你的栈
cp -r rules/python ~/.claude/rules/ecc/
cp -r rules/golang ~/.claude/rules/ecc/

🖥️ 桌面仪表盘

npm run dashboard 或 python3 ecc_dashboard.py：分页浏览 Agents/Skills/Commands/Rules，明暗主题 + 字体自定义。

🛡️ 安全扫描

npx ecc-agentshield scan，或 Claude Code 里 /security-scan；--fix 自动修安全项。

🔧 生命周期

node scripts/ecc.js doctor|repair|uninstall --dry-run 自检与清理，只读删自己装的文件。
