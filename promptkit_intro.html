你的后端

onSend 把文本 POST 到 /api/chat
  • Provider 是中枢：用 ChatProvider 包裹应用根，组件树内才能共享会话状态，否则 MessageList/MessageInput 拿不到上下文。
  • onSend 是接缝：组件不关心你用哪个模型，只把文本交给你写的回调函数，由你决定调用 OpenAI、Claude 还是自建推理服务。
  • onRegenerate 同理：用户点「重新生成」时回调触发，你去后端重跑一次并回流新消息。

③ 真实用法代码

# 1) 安装组件库（基于 Radix UI，无额外运行时依赖）
npm install @prompt-kit/react

# 2) 若项目还没有 peer 依赖
npm install react react-dom
// App.tsx —— 用 ChatProvider 包裹根部，把 onSend 接到自己的后端
import { useState } from "react";
import { ChatProvider, ChatWindow, MessageList, MessageInput }
  from "@prompt-kit/react";

export default function App() {
  const [messages, setMessages] = useState([]);

  // onSend 把输入接到你自己的 API，与模型选型解耦
  const handleSend = async (text: string) => {
    setMessages((m) => [...m, { role: "user", content: text }]);
    const res = await fetch("/api/chat", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ message: text }),
    });
    const data = await res.json();
    setMessages((m) => [...m, { role: "assistant", content: data.reply }]);
  };

  return (
    <ChatProvider>
      <ChatWindow>
        <MessageList messages={messages} />
        <MessageInput onSend={handleSend} />
      </ChatWindow>
    </ChatProvider>
  );
}
⚠️ 该示例为真实可用的结构骨架：组件名、import 路径、onSend 回调均取自官方用法；Props 字段名（如 messages / onSend）以官网为准，落地前对照你安装的版本文档核对一次即可。
FAQ

常见疑问

01

Prompt Kit 绑定了某个大模型吗？

＋
不绑定。它纯粹是「界面层」组件库，不知道也不关心你后端用 OpenAI、Claude、开源模型还是自建推理。你通过 onSend / onRegenerate 回调自己接 API，模型选型与组件完全解耦。
02

它和 shadcn/ui、Vercel AI SDK 是什么关系？

＋
定位不同，可叠加使用：
  • shadcn/ui 是通用表单/按钮等基础组件，不带「聊天语义」。
  • Vercel AI SDK 管的是「模型调用 + 流式」的运行逻辑，不带 UI。
  • Prompt Kit 专做 AI 聊天 UI 原语，底层复用 Radix 的可访问性基元。常见组合是：AI SDK 管后端、Prompt Kit 管前端。
03

可访问性做到什么程度？

＋
遵循 WCAG 2.1 标准：键盘可操作（Tab/Enter 走完对话）、正确的 ARIA 角色与状态、可见焦点环。因为基元来自 Radix UI，这些能力是「默认开启」的，而非事后打补丁。
04

如何自定义主题和样式？

＋
两种方式：
  • CSS 变量：覆盖官方暴露的设计令牌（颜色、圆角、间距），改一处全站生效。
  • styled-components / CSS-in-JS：对单个组件做精细换肤，匹配品牌色板与深色模式。
05

长对话历史会卡吗？

＋
不会。MessageList 使用虚拟滚动，只渲染视口内的消息节点。即便会话累积到几千条，DOM 节点数也维持在一个小常数，滚动保持流畅。
06

支持哪些 React 版本？

＋
作为 React 组件库，需要 React 18+ 的运行环境（hooks 与并发特性）。安装时请确保项目已具备 react / react-dom 作为 peer 依赖。
Quick Start

快速开始

三条路径：装包即用、最小 Demo 跑通、再做主题定制。建议先跑通最小 Demo 再换皮。

# 安装 Prompt Kit（核心包为 @prompt-kit/react）
npm install @prompt-kit/react

# 安装 React 运行时（若尚未存在）
npm install react react-dom
⚠️ 组件以 @prompt-kit/react 形式发布；无需额外装 Radix，可访问性基元已随包带入。
// main.tsx —— 挂到根，立刻跑通一个回显对话
import React from "react";
import { createRoot } from "react-dom/client";
import App from "./App";

createRoot(document.getElementById("root")!).render(<App />);

// App.tsx
import { ChatProvider, ChatWindow, MessageList, MessageInput }
  from "@prompt-kit/react";

export default function App() {
  const msgs = [{ role: "assistant", content: "Hi，我是 Prompt Kit 聊天窗。" }];
  return (
    <ChatProvider>
      <ChatWindow>
        <MessageList messages={msgs} />
        <MessageInput onSend={(t) => console.log(t)} />
      </ChatWindow>
    </ChatProvider>
  );
}
💡 把 onSend 里的 console.log 换成你的 fetch('/api/chat')，就接上了真实后端。
