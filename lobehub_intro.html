Overview

一个平台，六块能力

LobeHub 不是「又一个聊天 UI」。它把聊天界面、Agent 编排、模型接入、插件体系、多模态与开源部署打包成一层可自托管、可扩展的基础设施。

💬

LobeChat 聊天界面

基于 Next.js + TypeScript 的现代化会话 UI，支持多会话、多模型对比、知识库(RAG) 与本地优先体验，是 LobeHub 的旗舰开源项目。

🤖

Agent 市场

用 JSON 描述角色(SystemRole / 模型 / 参数)，即可发布到公开 Agent 市场，一键导入。报告提到它支持创建、部署、管理 7×24 运行的智能体团队。

🔌

模型接入层

统一适配 100+ 供应商：OpenAI、Anthropic、Google Gemini、Mistral、DeepSeek，以及本地 Ollama / LM Studio。一套配置切换全部模型。

🧩

插件 / 工具调用

原生 function calling 与插件机制，可接 Gmail、Slack、Notion 等外部服务 API，并支持 MCP（Model Context Protocol）扩展工具。

🖼️

多模态

视觉识别(上传图片理解)、TTS 语音合成、文生图(接 DALL·E / Flux) 等能力内建在会话流里，无需额外拼装。

🌐

开源 / 自托管

MIT 协议，Vercel 一键部署、Docker 镜像、Sevalla 等多种形式。数据留在自己手里，可离线跑本地模型。

② 本地部署：三种真实路径

# A. 源码启动（开发 / 改代码）——推荐 pnpm
git clone https://github.com/lobehub/lobe-chat.git
cd lobe-chat
pnpm install
pnpm dev          # 默认 http://localhost:3010

# B. Docker 一键起（生产自托管，端口 3210）
docker run -d -p 3210:3210 \
  -e OPENAI_API_KEY=sk-xxxx \
  --name lobechat \
  lobehub/lobe-chat

# C. Vercel 一键部署（网页点一下即可，无需本地）
# 打开 https://lobehub.com/zh/self-hosting ，点 Deploy 授权仓库即可
💡 端口差异：源码 pnpm dev 默认 3010，Docker 官方镜像默认 3210。本机同时跑多个实例时，用 -e PORT=xxxx 或 -p 新端口:3210 避开冲突。

③ 配置 .env：把密钥与模型交给环境变量

LobeChat 把密钥与供应商开关全部走环境变量，不写进代码库。最小可用配置如下（.env 放项目根目录）：

# 云端模型
OPENAI_API_KEY=sk-xxxx
OPENAI_MODEL=gpt-4o

# 本地模型（Ollama，无需联网）
OLLAMA_MODEL_LIST=qwen2.5:7b,llama3:8b

# 可选：开启单点登录 / 数据持久化
ENABLE_OAUTH_SSO=false
NEXT_PUBLIC_SERVICE_MODE=server

④ 写一个 Agent：纯 JSON，无需编译

Agent 市场里的角色就是一份结构化 JSON（schema 见下方）。改完在 LobeChat「角色设置 → 导入」即可加载，也能推到社区市场分享。

// translator-pro.json —— 一份可直接导入的 Agent 定义
{
  "schemaVersion": 1,
  "identifier": "translator-pro",
  "meta": { "title": "专业中英翻译", "avatar": "🌐" },
  "model": "gpt-4o",
  "systemRole": "你是一名专业本地化译员，只输出翻译结果，保留术语表。",
  "params": { "temperature": 0.3, "max_tokens": 2048 }
}
🧩 插件与 MCP：除了角色 JSON，LobeChat 还能在设置里挂载插件（如联网搜索、网页抓取）与 MCP Server，把外部 API 变成 Agent 可调用的工具，对应报告里「连接 Gmail / Slack / Notion」这类集成场景。

FAQ

常见问题

01

LobeHub 和 LobeChat 是什么关系？

＋
LobeHub 是组织 / 品牌名，旗下开源产品统称；LobeChat 是其中的旗舰项目——那个你实际部署、打开聊天的 Next.js 聊天应用。此外还有 LobeUI（组件库）、LobeTheme 等配套仓库。简单说：用 LobeChat 就是在用 LobeHub 的开源成果。
02

一定要会写代码才能用吗？

＋
不一定要。最省事的方式是去官网或 lobehub.com/zh/self-hosting 点 Vercel 一键部署，填好 API Key 就能用，全程网页操作。只有想改源码、自托管或与内部系统集成时才需要碰命令行与 .env。
03

能完全离线、数据不出本机吗？

＋
可以。把模型接入层指向本地 Ollama 或 LM Studio（设置 OLLAMA_MODEL_LIST），再关闭任何需要联网的插件，整套推理就在你机器上完成。报告也强调它适合「7×24 运行」的私有 Agent 场景。
04

Agent 市场和插件怎么用？

＋
Agent 市场里每个角色都是一份 JSON 配置（含 systemRole、默认模型、参数），可一键导入到自己的 LobeChat。插件则把 Gmail / Slack / Notion / 联网搜索等外部能力封装成 Agent 可调用工具，新版还支持 MCP 协议挂载任意兼容 Server。
  • 角色导入：设置 → 角色 → 导入 JSON
  • 插件：设置 → 工具 / 插件 中开启
  • MCP：设置 → MCP Servers 添加
05

和 ChatGPT / 商业产品比，优势在哪？

＋
核心是所有权与可组合性：① 模型任选（不被绑死在一家）；② 数据自托管、可私有部署；③ 角色 / 插件 / MCP 全开放，能接内部系统；④ MIT 协议可二次开发。代价是需要自己部署与维护（或用 Vercel 一键托管）。
06

性能与硬件要求高吗？

＋
纯云端模型时，LobeChat 只是个前端 + 代理，普通服务器即可。要跑本地模型则看模型大小：7B 级别量化模型约需 8GB 内存，13B 建议 16GB+。Docker 镜像已带好运行环境，开箱即用。
Quick Start

三种方式快速开始

不想折腾就走 Vercel 一键；要改代码走源码；要长期自托管走 Docker。三条路不要叠加，选一条即可。

# 无需命令行：打开自托管页 → 点 Deploy → 授权 GitHub
# 1) 浏览器访问：
https://lobehub.com/zh/self-hosting

# 2) 在 Vercel 面板填入环境变量
OPENAI_API_KEY=sk-xxxx

# 3) 等构建完成，自动分配 *.vercel.app 域名，直接聊天
⚠️ 免费额度有限。生产自托管建议绑定自己的域名，并在环境变量里只放最小可用密钥。
# 克隆并安装（pnpm 优先）
git clone https://github.com/lobehub/lobe-chat.git
cd lobe-chat
pnpm install

# 写入密钥后启动开发服务器
echo 'OPENAI_API_KEY=sk-xxxx' > .env
pnpm dev        # http://localhost:3010

# 生产构建
pnpm build && pnpm start
💡 想接本地模型，把 OPENAI_API_KEY 换成 OLLAMA_MODEL_LIST 即可，无需云端 Key。
# 拉起官方镜像（默认端口 3210）
docker run -d -p 3210:3210 \
  -e OPENAI_API_KEY=sk-xxxx \
  -e ACCESS_CODE=你的访问口令 \
  --name lobechat \
  lobehub/lobe-chat

# 查看日志 / 停止
docker logs -f lobechat
docker stop lobechat
🔒 公网暴露时务必设 ACCESS_CODE，否则任何人都能用你的 Key 刷模型。

🧪 导入 Agent

把上面的 translator-pro.json 在「角色 → 导入」里加载，立刻拥有专属翻译 Agent。

🧩 加插件

设置里开启联网搜索 / 网页抓取，或添加 MCP Server 接入内部工具。

🖥️ 本地模型

安装 Ollama 后填 OLLAMA_MODEL_LIST，离线也能对话。
