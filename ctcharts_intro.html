Overview

它不是「又一个 GitHub 榜单」，而是一份增长榜

和按 star 总量排的静态榜不同，Chinese Top Charts 关注的是「增量」：哪些中文开源项目在最近真正涨得最快。下面是它解决的核心问题。

📈

趋势追踪

按 star/fork 等增长指标排序，直接看到「现在什么在涨」，而不只是历史总量。

🔄

每日更新

维护者用定时任务每天拉取数据、重新生成榜单并提交，榜单永远反映最新一周的走势。

🗂️

分类筛选

榜单按「增长 / 知识」等维度、再按语言（All-Language 等）拆分，想看哪类点开即可。

🔎

发现优质项目

把国内正在高速成长、但还没被大众熟知的仓库推到你面前，省去刷信息流的时间。

🌐

社区融入

通过榜单快速摸清国内开发者在关注什么技术方向，是融入中文开源生态的入口。

🤝

开放贡献

仓库完全开源，漏掉的好项目可以通过 Issue 或 PR 申请收录，榜单靠社区一起补全。

Deep Dive

榜单到底是怎么来的

它本质是一个「数据抓取 + 自动生成 Markdown 榜单」的开源仓库，没有后端服务，全靠 GitHub Actions 类的定时任务驱动。

① 抓取

定时调用 GitHub API 拉取候选中文仓库的 star / fork 等计数
→

② 统计

按时间窗口计算增量，得到「增长幅度」与「增长速度」
→

③ 生成

把结果写成排序好的 Markdown 表格，落进 content/charts/ 目录
→

④ 提交

每日自动 commit 回仓库，GitHub 页面即实时榜单
💡 数据来源：所有数字来自 GitHub 公开 API，榜单仓库本身不含数据库，原始数据以 .md 表格形式直接存在 git 历史里——所以你既能在线看，也能把整个仓库 clone 下来离线翻。

本地把榜单拉下来看

# 1) 克隆仓库到本地
git clone https://github.com/Hnitrogen/Chinese-Top-Charts.git
cd Chinese-Top-Charts

# 2) 直接读「全语言增长榜」（知识维度）
cat content/charts/growth/knowledge/All-Language.md

# 3) 列出所有榜单文件，按维度/语言挑着看
find content/charts -name "*.md" | sort
📊 榜单衡量的是「增量」而非「存量」：一个 50k star 但三个月没涨的老项目，排名会低于一个 3k star 但周涨 800 的新项目。这正是它能帮你发现「早期信号」的原因。
How To Read

怎么读这份榜：维度与语言

榜单按「维度」和「语言」两级组织。先看维度，再下钻到你关心的语言栈。

增长榜 growth 知识榜 knowledge 全语言 All-Language 按语言拆分 每日快照

🧭 维度（growth / knowledge）

  • growth：综合增长幅度与速度的项目榜，主榜
  • knowledge：偏教程、文档、学习类资源的增长榜
  • 每个维度下都有一份 All-Language.md 总表

🔤 语言下钻

  • 在维度目录内按语言拆出独立文件，方便只看某一栈
  • 如想找 Rust / Go / Python 方向的增长项目，直接定位对应文件
  • 不确定有哪些语言？用上面的 find 命令全列出来

只看某一语言的增长榜

# 在增长榜里筛出含 "Python" 字样的条目
grep -i "Python" content/charts/growth/knowledge/All-Language.md

# 列出所有按语言拆分的榜单文件
ls content/charts/growth/knowledge/

# 想把结果存成自己的清单
grep -i "Rust" content/charts/growth/knowledge/All-Language.md > my-rust-watchlist.md

FAQ

常见问题

01

Chinese Top Charts 是什么？

＋
它是一个 GitHub 开源项目，持续追踪并统计中文开源项目的增长趋势。数据每天更新，把国内正在快速上涨的优质仓库排成榜，帮助开发者发现好项目、看技术风向、融入中文社区。
02

它和普通的 GitHub Trending 有什么不同？

＋
区别在于聚焦「中文项目」+ 关注「增量」：
  • 普通 Trending 是全球范围、按短期热度排
  • 这里专门筛中文开源项目，且按 star/fork 的增长幅度与速度排序，而非历史总量
  • 数据落进 git 仓库的 .md 表格，可离线翻、可追踪历史
03

数据多久更新一次？来源可靠吗？

＋
仓库维护者用定时任务每日拉取 GitHub 公开 API、重新生成榜单并提交回仓库，所以页面每天都是最新。原始数据来自 GitHub 官方 API，但本页的汇总数字（项目数、语言数、Star/PR 数）为基于仓库结构的估算，未独立核验。
04

榜单按什么维度组织？

＋
两级结构：维度（如 growth 增长榜、knowledge 知识榜）× 语言（如 All-Language 总表、各语言拆分文件）。路径形如 content/charts/growth/knowledge/All-Language.md，直接 clone 后用 find/grep 检索即可。
05

好项目没被收录，怎么加进去？

＋
仓库完全开源，提交方式有两种：
  • 开一个 Issue 说明项目地址与理由
  • 或直接在数据里提 PR 申请收录
维护者审核后会纳入候选池，进入每日的抓取与排名流程。
06

需要安装什么才能用吗？

＋
不需要。纯浏览直接打开 GitHub 页面即可；想离线/批量检索只需 git clone 加任意文本工具（cat、grep、find）。榜单是静态 Markdown，不依赖任何运行时或后端服务。
Quick Start

三种上手方式

从零门槛的在线浏览，到本地离线检索，再到参与贡献——挑你顺手的。

# 直接打开全语言增长榜（知识维度）的实时页面
open https://github.com/Hnitrogen/Chinese-Top-Charts/blob/master/content/charts/growth/knowledge/All-Language.md

# 或只想看原始 Markdown 文本（适合 curl 抓取后再处理）
curl -sL https://raw.githubusercontent.com/Hnitrogen/Chinese-Top-Charts/master/content/charts/growth/knowledge/All-Language.md
💡 想每天收到更新？在仓库页点 Watch / Star，GitHub 会在榜单有新 commit 时推送通知。
# 1) 克隆仓库（Tabbit 报告给出的官方命令）
git clone https://github.com/Hnitrogen/Chinese-Top-Charts.git
cd Chinese-Top-Charts

# 2) 看全语言增长总表
cat content/charts/growth/knowledge/All-Language.md

# 3) 按语言下钻 + 存成自己的观察清单
grep -i "Go" content/charts/growth/knowledge/All-Language.md > go-watch.md
📌 整个榜单就是一组 Markdown 文件，没有任何构建步骤。clone 完即可用任意编辑器或命令行工具离线检索。
# 方式 A：开 Issue 申请收录（适合不想碰代码）
open https://github.com/Hnitrogen/Chinese-Top-Charts/issues/new

# 方式 B：Fork → 改数据 → 提 PR（适合想直接加项目）
git fork https://github.com/Hnitrogen/Chinese-Top-Charts.git
cd Chinese-Top-Charts
# 编辑对应维度的 Markdown，加入项目行后：
git add -A && git commit -m "add: 收录 xxx 项目"
git push && open https://github.com/Hnitrogen/Chinese-Top-Charts/compare
⚠️ 提交前先在 All-Language.md 里确认项目未被收录，避免重复 PR。说明理由（增长数据、项目价值）能提高通过率。
